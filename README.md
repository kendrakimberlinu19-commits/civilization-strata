# 文明地层 · 遗迹档案站

黑色展台、石质档案袋和六层文明线索。可编辑的原生 HTML/CSS/JavaScript 项目，无需安装运行依赖。

六个主题：生计与土地、定居与协作、文字与决策、材料与技艺、信仰与图像、港口与相遇。每层4份，共24份档案，另含主题图解、补充图组和6个视频。

## 本地运行

Node.js 18+，执行 `npm start` 后访问 http://127.0.0.1:4173/ 。局域网使用 `npm run start:lan`，并打开终端给出的 LAN 地址。浏览器需支持 ES modules，不能直接双击 HTML。

`npm test` 检查数据、拖动惯性、手势逻辑和钱币模型；`npm run build` 生成 dist/ 静态版本。

## 编辑素材

- data/archive.js：24份记录、解读、来源、图组和视频目录。
- data/theme-stories.js：6个主题的标题、序言、顺序、主题图片、图解和视频路径。
- data/exhibit.js：档案袋图片与轮盘装饰。
- assets/images/layers/s01 至 s06：当前主题网页图片，保留原色，详情使用完整图。
- assets/videos/：各主题视频，内页按需加载。第五层为壁画与洞窟资料制作的45秒图像短片，其余保留提供文件的实际时长。
- scroll-dialog.css：卷轴详情、项目说明、目录与视频面板。
- ambient-sound.js：默认开启的轻微反馈声，首次操作后启动，可静音及调整音量。

新增记录需填写唯一编号并加入对应主题 cardIds；组件不限制固定数量。调整主题数后，档案袋与轮盘自动使用数据长度。

## 发布

GitHub Pages 从 main 分支的 docs/ 目录发布，仓库根目录为可编辑源码。图片和视频使用相对路径，主题使用 hash 路由。原始 Word、录屏、凭据和本地检查资料不包含在发布文件中。

## 内容说明

主题顺序是策展阅读线索，不代表同一遗址的实际地层或线性年代。实物资料、工艺示意与策展解读分开组织，资料入口可在详情展开查看。素材来源以各记录保留的信息为准，不在本仓库额外授予第三方转载或再利用权利。

## 字体

字体文件随站点提供，不依赖字体 CDN。标题为思源宋体的网页子集，正文和控件为思源黑体子集，编号保留 Georgia。统一样式位于 typography.css；assets/fonts/ 中保留字体和原始 OFL 许可。修改大量文案后需重建字形子集；未覆盖字形采用系统回退。详见 assets/fonts/README.md。

## 三维观察

六个主题的内页末尾各有两个可操作模型，共12件。可从目录选择“三维观察”，点击载入后拖动旋转、滚轮或双指缩放，也可使用方向键和视角按钮。模型不自动旋转，退出内页释放查看器。

`data/models.js` 管理名称、主题、模型路径、预览图、初始视角与来源；`assets/models/` 为网页副本，采用 Draco 几何压缩和 2048px WebP 贴图，合计约14.37MB。原始 GLB 保留在用户本机，不进入发布仓库。`model-gallery.js`、`model-gallery.css` 实现展台，首次点击才加载查看器和模型。查看器及解码器位于 `assets/vendor/model-viewer/`，随网站本地提供。

## 参观手册

首页左下角和档案展台设有“参观手册”按钮，打开羊皮纸卷轴，含网站介绍、六主题速览、图文与视频、声音、三维模型、摄像头手势、键盘触摸和常见问题。支持章节跳转、Esc关闭与关闭后恢复入口焦点。手册文案集中在 data/visitor-guide.js，展示与样式为 visitor-guide.js 和 visitor-guide.css；复用已有卷轴底图，不新增图像或运行依赖。
